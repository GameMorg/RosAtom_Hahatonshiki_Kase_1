# Модуль 2. Нейросетевая модель (Vanilla)

Код: `eos/model.py` (`EOSNet`, `Thermo`), `eos/train.py`. Запуск:

```bash
python scripts/m2_m3_train.py --config configs/vanilla.json
```

## Постановка
Сеть аппроксимирует (ρ, T) → (P, E) по train-узлам (см. модуль 1), без физических слагаемых.

* Вход: x = ((ln ρ − μ)/σ, (ln T − μ)/σ) ∈ [−1, 1]² — логарифмы выравнивают диапазоны в 7 и 8 порядков;
  для lin-сеток (ρ ∈ [1.5, 5], T ∈ [3·10⁴, 10⁵]) диапазон всего ×3.3, поэтому log-координаты там почти равномерны.
* Выход: y = (нормированный ln P, нормированный asinh(E / 1 кДж/г)) — ошибка MSE в этих координатах
  ≈ относительная ошибка P и E, что соответствует физическому смыслу точности УРС.
* Обратное преобразование: P = exp(·), E = sinh(·) — P > 0 гарантирован конструктивно.

## Архитектура и её выбор
`EOSNet`: 32 случайных Фурье-признака sin/cos(π·B·x) (B ~ N(0, 2²)) → 5 скрытых слоёв × 128, SiLU → 2 выхода.
≈ 75 тыс. параметров, ≈ 0.3 МБ.

Короткие запуски (100 эпох, ошибка на val, P / E):

| вариант | P | E |
|---|---|---|
| 5×128 SiLU, без Фурье | 2.0 % | 2.4 % |
| 4×256 SiLU | 2.2 % | 2.6 % |
| 5×128 tanh | 1.4 % | 1.5 % |
| Фурье 16, σ=1 | 0.77 % | 1.1 % |
| **Фурье 32, σ=2** | **0.53 %** | **0.84 %** |
| Фурье 64, σ=3 | 0.55 % | 0.85 % |
| Фурье 32, σ=4 | 0.79 % | 1.5 % |

Фурье-признаки снимают «спектральное смещение» MLP и позволяют описать резкие переходы
(ионизационный рост E при T ~ 10⁴ K, структура холодной кривой при ρ ≈ 2–3 г/см³).
Гладкая активация (SiLU) обязательна: производные выходов по входам участвуют в физике.

## Обучение
Adam, lr 2·10⁻³ → 10⁻⁵ (косинус), батч 4096, 300 эпох, clip_grad_norm = 1. ≈ 9 мин на 2 ядрах CPU.
История — `artifacts/models/vanilla_history.csv`, кривые — `artifacts/figures/m2_learning_curves.png`.

Результат на val: средняя относительная ошибка P ≈ 0.23 %, E ≈ 0.25 % (на test — в итоговой таблице).

## Производные через autograd (п. 2.3)
* **Эталон — `torch.autograd`:** `eos.model.autograd_derivatives(net, th, rho, T)` и `EOSModel(".pt").derivatives_autograd(rho, T)`
  дают ∂P/∂ρ, ∂P/∂T, ∂E/∂ρ, ∂E/∂T и c_s² по физическим входам ρ, T.
* `python scripts/m2_autograd_derivatives.py --models pinn pinn_thermo` считает их **во всех 278 537 тестовых точках**,
  сохраняет выборку в `artifacts/tables/autograd_derivatives_<model>.csv` и отчёт `autograd_derivatives_report.json`.
* **Ускоренный эквивалент — явный якобиан** `EOSNet.forward_jac` (касательные протаскиваются через слои за один проход).
  Он нужен, потому что autograd нельзя экспортировать в ONNX, а гидрокоду нужны производные и c_s прямо в модели.
  Расхождение с autograd на всех test-точках — медиана 4·10⁻⁷…8·10⁻⁷ (точность float32); тесты — до 10⁻¹² в double.
* При обучении PINN можно выбрать способ производных в физических потерях: `"deriv": "autograd"` (через
  `torch.autograd.grad(..., create_graph=True)`) или `"jac"` (по умолчанию, тот же результат быстрее).

## Физика Vanilla
На 50 тыс. случайных точек по всей области у Vanilla ≈ 28 % точек нарушают устойчивость
(C_v < 0 ≈ 25 % — мелкие отрицательные наклоны на «плато» E(T) при низких T; ∂P/∂ρ ≤ 0 ≈ 4 %; c_s² ≤ 0 ≈ 3 %).
Точная сетка ≠ физичная модель — это мотивирует модуль 3.
