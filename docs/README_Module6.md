# Модуль 6. Презентация проделанной работы

* `docs/presentation.pptx` (и `docs/presentation.pdf`) — 16 слайдов в корпоративной стилистике Росатома (светлые слайды, синие ленты с ключевыми цифрами, инфографика, плавные переходы):
  команда, результат в цифрах, данные и находка о несогласованности таблиц, бейзлайн, архитектура,
  Vanilla vs PINN, физическая функция потерь, компромисс по Максвеллу, итоговая таблица, карты ошибок,
  инференс, сжатие, итоги. На ключевых слайдах есть заметки докладчика.
* `docs/documentation.docx` (и `docs/documentation.pdf`) — итоговая документация решения (формат Word/PDF по ТЗ).

Все цифры и рисунки в них взяты из `artifacts/tables/*` и `artifacts/figures/*`
(рисунки пересоздаются скриптами `scripts/m1_eda_baseline.py` и `scripts/m4_evaluate.py`).
