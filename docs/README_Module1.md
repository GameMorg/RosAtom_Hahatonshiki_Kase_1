# Модуль 1. Данные, EDA и билинейный бейзлайн

Скрипт: `scripts/m1_eda_baseline.py`. Код: `eos/data.py`, `eos/baseline.py`, `eos/physics.py`, `eos/metrics.py`.

```bash
python scripts/m1_eda_baseline.py --data data/raw --out artifacts
```

## 1.1 Данные

20 файлов `Obl01.txt … Obl20.txt`, всего 1 130 053 точки. Колонки: ρ [г/см³], T [K], P [ГПа], E [кДж/г].
Каждая область — **полная прямоугольная сетка**, равномерная по каждой оси либо линейно, либо логарифмически.
Встречаются все 4 типа: log-log (13 областей), log-lin (4), lin-log (4), lin-lin (1, Obl14).

| | A: 1e-3…0.1 | B: 0.1…1.5 | C: 1.5…5 (lin) | D: 5…1e4 |
|---|---|---|---|---|
| T1: 0.1…100 K | 01 | 06 | 11 | 16 |
| T2: 100…3e3 K | 02 | 07 | 12 | 17 |
| T3: 3e3…3e4 K | 03 | 08 | 13 | 18 |
| T4: 3e4…1e5 K (lin) | 04 | 09 | 14 | 19 |
| T5: 1e5…1e7 K | 05 | 10 | 15 | 20 |

Карта областей: `artifacts/figures/m1_regions.png`, поверхности lg P и asinh E: `m1_maps_P_E.png`.

Наблюдения:
* P > 0 во всей области (от 5·10⁻⁴ до 1.6·10⁹ ГПа — 12 порядков) ⇒ целевая переменная для сети — ln P;
* E меняет знак (от −46.8 до 1.8·10⁵ кДж/г) ⇒ используем asinh(E / 1 кДж/г): линейно у нуля, логарифмически на больших |E|;
* NaN/дубликатов нет; на общих границах областей значения непрерывны (расхождение P < 0.1 %, кроме одной границы — 3.8 %);
* в T-областях узлы не доходят до границы ровно (например, T1 кончается на 95.7 K) — между областями есть узкие «щели», модель обязана интерполировать и там.

## 1.2 Сечения
`m1_sections.png` — P и E при ρ = 0.01; 0.5; 2.7; 100 г/см³ и T = 1; 10³; 3·10⁴; 10⁶ K.
Видны: «холодная» кривая P ∝ ρ^{5/3} (вырожденный электронный газ), резкий рост E при T ≈ 10⁴ K (ионизация) при низких ρ,
немонотонная структура E(ρ) около нормальной плотности (2–3 г/см³), ступенька при T ≈ 143 K.

## 1.3 Проверка термодинамики на самих таблицах (ключевая находка)

Производные таблиц — центральные разности по узлам (`eos.physics.grid_derivatives`), рисунки `m1_data_physics.png`, `m1_cold_curve_and_step.png`, таблица `artifacts/tables/data_physics_by_region.csv`.

| Ограничение | Выполнение в данных |
|---|---|
| (∂P/∂ρ)_T > 0 | **везде** |
| C_v = (∂E/∂T)_ρ ≥ 0 | везде, **кроме одной линии T ≈ 143 K** (скачок E и P во всех областях T2 — артефакт сшивки модели) |
| c_s² > 0 | везде, кроме той же линии |
| c_s < c | нарушается при T → 0 (E не зависит от T ⇒ C_v = 0, но ∂P/∂T ≠ 0 ⇒ c_s² → ∞) |
| ρ²(∂E/∂ρ)_T = P − T(∂P/∂T)_ρ | **не выполняется**: медиана \|r_M\| = 0.29, у 70 % узлов \|r_M\| > 5 % |

В холодной области ρ²∂E/∂ρ ровно в 2 раза меньше P (P ∝ ρ^{5/3}, E ∝ ρ^{2/3} с коэффициентом вдвое меньше согласованного);
минимум E_cold — при ρ ≈ 2.6 г/см³, но P там ≈ 140 ГПа, а не 0. То есть таблицы P и E не происходят из одной свободной энергии.

**Следствие для PINN:** условия устойчивости совместимы с данными — их можно навязывать без потери точности;
условие Максвелла с данными несовместимо — его можно вводить только как штраф с компромиссом «точность ↔ согласованность» (см. модуль 3).

## 1.4 Разбиение и нормирование
Для каждой области (`eos.data.split_masks`):
* **train** — узлы с чётными индексами (i, j) (+ последние узлы по осям) — «прореженная» вдвое сетка, 286 521 точка;
* **test** — узлы (нечётный i, нечётный j) — центры ячеек train-сетки, 278 537 точек: самые трудные точки для интерполяции;
* **val** — середины рёбер, 564 995 точек.

И бейзлайн, и сети видят **только train**, поэтому сравнение честное.

Нормирование (`artifacts/models/normalization.json`, класс `Normalizer`):
x_ρ = (ln ρ − μ)/σ, x_T = (ln T − μ)/σ, отображающие всю область в [−1, 1]²;
y_P = (ln P − μ_P)/σ_P, y_E = (asinh(E/E_s) − μ_E)/σ_E, E_s = 1 кДж/г.

## 1.5 Бейзлайн: билинейная интерполяция

`BilinearEOS`: по каждой из 20 областей — `scipy.interpolate.RegularGridInterpolator` в **нативных координатах** сетки
(ln для log-осей, сама величина для lin-осей), т.е. в каждой ячейке интерполяция идёт по равномерной сетке.
Варианты значений: `raw` (P, E) и `log` (ln P, E). Производные для проверки физики — центральные разности.

Результат на test (центры ячеек):

| | P: MAPE | P: p95 | P: max | E: ср. отн. | E: p95 | Размер | 10⁵ запросов |
|---|---|---|---|---|---|---|---|
| bilinear raw | 0.055 % | 0.20 % | 21.9 % | 0.027 % | 0.085 % | 4.4 МБ | ≈ 35–50 мс |
| bilinear log | **0.012 %** | 0.013 % | 20.4 % | 0.027 % | 0.085 % | 4.4 МБ | ≈ 50–70 мс |

Максимальные ошибки — на ступеньке T ≈ 143 K. Полная таблица (без прореживания) весит ≈ 17 МБ.
Бейзлайн очень точен в узлах сетки — нейросеть выигрывает у него не по точности в узлах, а по компактности,
гладким производным и выполнению физических ограничений (см. итоговую таблицу в README).
